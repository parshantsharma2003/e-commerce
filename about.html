About MyMart

MyMart is a mini e-commerce web application designed to simulate a real online shopping experience using only HTML, CSS, and JavaScript.

🎯 Purpose

The purpose of MyMart is to help learners understand how real-world e-commerce platforms work, including product listing, cart management, login systems, and UI interactions.

🛠 Technologies Used

  • HTML5 for structure
  • CSS3 for design & animations
  • JavaScript for logic & interactivity
  • LocalStorage for data persistence
  • GitHub Pages for hosting

✨ Features

  • User Login & Signup (JS only)
  • Dynamic product rendering
  • Category filtering & search
  • Add to cart with animations
  • Persistent cart system
  • Responsive modern UI

👨‍💻 Developer Note

This project was built as a learning-focused and portfolio-ready application, following clean UI principles and modern frontend practices.
